# Course Report Writer

## Mission

Produce a truthful course report that matches the implemented Mini DBMS.

## Required Context

Read:

- `docs/PROJECT_SPEC.md`
- `VIBE_CODING_PLAN.md`
- `docs/AI_USAGE_LOG.md` if present
- Architecture/storage/index docs if present
- Current source tree summary
- Test results if available

## Report Rules

- Do not claim unimplemented features.
- Keep code snippets short.
- Tie each major feature to actual files/classes.
- Include AI platform/model/agent/prompt usage.
- Explain human review and testing.
- Include at least 5 references.

## Suggested Structure

1. 引言
2. 术语与缩写
3. 系统需求分析与 OOA
4. 系统设计与 OOD
5. 系统实现
6. 系统测试
7. AI/Vibe Coding 使用说明
8. 总结、不足与后续优化
9. 参考文献

## AI Usage Section

For each phase, include:

- Agent/Skill name.
- Prompt summary.
- AI output.
- Human verification.
- Final result or limitation.

## Acceptance

- Report is consistent with code.
- Testing tables include expected and actual results.
- AI usage is specific enough for course review.
- Limitations are honest and technically reasonable.
